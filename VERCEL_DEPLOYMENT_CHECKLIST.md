## GoDaddy Domain Connection

### Setup Nameservers (Recommended Method)
- [ ] Log into GoDaddy account
- [ ] Go to "My Products" → "Domains"
- [ ] Select your domain
- [ ] Go to "Manage" → "Nameservers"
- [ ] Change to "Custom Nameservers"
- [ ] Add Vercel's nameservers:
  - `ns1.vercel-dns.com`
  - `ns2.vercel-dns.com`
  - `ns3.vercel-dns.com`
  - `ns4.vercel-dns.com`
- [ ] Save changes

### Vercel Domain Configuration
- [ ] In Vercel Dashboard, go to your project
- [ ] Click "Settings" → "Domains"
- [ ] Click "Add Domain"
- [ ] Enter your GoDaddy domain name
- [ ] Select "Use Vercel Nameservers"
- [ ] Wait for verification (24-48 hours)

### Verify Domain Connection
- [ ] Check domain status in Vercel Dashboard
- [ ] Status should change from "Pending" to "Active"
- [ ] Visit your domain in browser: `https://yourdomain.com`
- [ ] Verify SSL certificate is active (padlock icon)
- [ ] Check both `yourdomain.com` and `www.yourdomain.com`

## Alternative: Manual DNS Setup (GoDaddy)
*Only if you don't want to change nameservers*

- [ ] In Vercel, note the DNS records provided
- [ ] Log into GoDaddy
- [ ] Go to domain → "DNS"
- [ ] Add A record pointing to Vercel IP
- [ ] Add CNAME record for `www` subdomain
- [ ] Wait 24-48 hours for propagation

## Troubleshooting

### Build Fails on Vercel
- [ ] Check build logs in Vercel Dashboard
- [ ] Ensure all environment variables are set
- [ ] Try building locally first: `npm run build`
- [ ] Check for missing dependencies in `package.json`

### Domain Not Connecting
- [ ] DNS changes can take 24-48 hours
- [ ] Use [DNS Checker](https://dnschecker.org) to verify propagation
- [ ] Check Vercel domain status regularly
- [ ] Clear browser cache or use incognito mode

### Pages Show 404
- [ ] Verify Next.js routing is correct
- [ ] Check middleware configuration
- [ ] Ensure all API routes are deployed

### Database Connection Issues
- [ ] Verify `DATABASE_URL` is correct in Vercel
- [ ] Check database is accessible from Vercel IPs
- [ ] Review Prisma connection pool settings
- [ ] Check database server is running and accepting connections
